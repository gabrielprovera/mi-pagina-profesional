Proyecto destacado

Pizzería Valentino

Sistema de gestión desarrollado para una pizzería, diseñado para facilitar la administración diaria del negocio.

El sistema permite gestionar pedidos, clientes, productos, stock, empleados, repartidores, formas de pago y generación de tickets.

Desarrollo realizado con Python, Tkinter y SQLite.
