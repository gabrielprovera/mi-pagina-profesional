Proyecto destacado

Pizzería Valentino

Necesidad: contar con un sistema que permitiera organizar las tareas diarias del comercio y centralizar la información del negocio.

Solución: desarrollé un sistema de gestión personalizado para administrar pedidos, clientes, productos, stock, empleados, repartidores y formas de pago.

Tecnologías: Python, Tkinter y SQLite.

Funcionalidades: gestión de pedidos, control de stock, administración de clientes y empleados, seguimiento de repartidores y generación de tickets.

El proyecto demuestra cómo un sistema desarrollado a medida puede adaptarse a las necesidades concretas de un comercio y facilitar su trabajo diario.
