Proyecto destacado

Pizzería Valentino

Sistema de gestión desarrollado para una pizzería, pensado para facilitar y organizar las tareas diarias del negocio.

El sistema permite gestionar pedidos, clientes, productos, stock, empleados, repartidores, formas de pago y generación de tickets.

Fue desarrollado con Python, Tkinter y SQLite, utilizando una base de datos para organizar la información del negocio.

Este proyecto es un ejemplo de cómo una solución de software a medida puede adaptarse a las necesidades concretas de un comercio.
